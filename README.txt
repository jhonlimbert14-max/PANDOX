PANDOX - plantilla inicial

Contenido:
- index.html: tienda estática con catálogo, búsqueda, filtros y carrito local.
- No procesa pagos ni guarda pedidos en una base de datos.
- Los productos y precios de ejemplo se editan en el arreglo `products` al final del archivo.
- Antes de vender, configura productos reales y conecta un backend seguro, un proveedor de pagos autorizado y proveedores de entrega autorizados.

Publicación sugerida:
1. Sube index.html a un repositorio de GitHub.
2. En Netlify, importa el repositorio desde Add new site / Import an existing project.
3. No necesitas comando de build; el directorio de publicación es la raíz.
